# Розгортання ПЛОЩІ

Одна машина з Docker (ноут годиться) + тунель Cloudflare. Роутер чіпати не треба.

## 1. Тунель

Cloudflare → Zero Trust → **Networks → Tunnels → Create a tunnel** → скопіювати токен.
Там же **Public hostname**: `<твій домен>` → `HTTP` → `core:8765`.

## 2. Замок на витрати

Дивитись село може будь-хто. Витрачати — ні: `POST /command` ставить тему в чергу.
Cloudflare → Zero Trust → **Access → Applications** → додати застосунок на шлях `/command`
з політикою «вхід поштою» (безкоштовно до 50 людей).

У ядрі стоїть ДРУГА, незалежна стеля: 6 команд на адресу за хвилину. Вона лишається на місці,
навіть якщо політику Access налаштують криво або пароль передадуть далі.

## 3. Запуск

```bash
cp infra/.env.example infra/.env   # заповнити ключ і токен тунелю
docker compose -f infra/docker-compose.yml up -d --build
docker compose -f infra/docker-compose.yml logs -f core
```

## 4. Що де живе

- стан сіл (черга, ухвали, чутки, памʼять, звʼязки) — том `state`, переживає перезапуск;
- село відвідувача, якого не торкались `PLOSHCHA_SESSION_TTL_DAYS` діб, прибирається;
- більше за `PLOSHCHA_MAX_SESSIONS` сіл не тримаємо — найдавніші йдуть першими.

## 5. Чого тут навмисно немає

- **проброшених портів**: ядро слухає `127.0.0.1` у контейнері, назовні дивиться лише тунель;
- **ключів у образі**: вони приходять зі змінних оточення при запуску;
- **дев-редактора розкладки**: `layout_editor.html` видаляється зі збірки, бо він без замка.
