# ПЛОЩА

**Живе, красиве 2D-українське село на моделі Lapa.** Generative-agents симуляція, де
кожен мешканець — автономний агент із памʼяттю, рефлексією, денним планом і стосунками:
селяни працюють, зустрічаються, розмовляють і разом проживають день, чиї маленькі драми
народжуються самі собою. Оповідач-літописець розказує цей день як хроніку. Жива діорама
в дусі стенфордського «Generative Agents» — і чесний тест Lapa на агентних задачах.

> Це чистий продовий репозиторій. Стара лабораторія (`~/lapa-arena`) — архів, з якого
> дістаємо готове. Канонічна ідея: [`docs/IDEA.md`](docs/IDEA.md).

## Структура (моно-репо)

```
contracts/     ★ заморожений контракт подій (джерело правди фронт↔бек)
packages/
  contract-ts/   TS-типи + zod-гарди зі схеми
  fixtures/      записані прогони (*.jsonl) — ганяють фронт без беку
apps/web/      Vite + TS + PixiJS — сцена, ролі, HUD, контролі
services/sim/  прод-бек (порожній до Фази 4; пишеться за SOLID/security)
data/          narrative_bank, personas, taxonomy, feeds, фікстури
eval/          golden-set + Lapa-проби (ресерч)
docs/          IDEA.md · adr/ · research/
infra/         docker-compose (без моделей і db)
```

## Запуск

```bash
pnpm install
pnpm dev      # → http://localhost:5177  (фронт ганяється на фікстурі quiet-day, 0 токенів)
pnpm build    # tsc --noEmit && vite build → apps/web/dist
```

Редактор села (розкладка будівель/міток/млина) — `http://localhost:5177/layout_editor.html`.

## Статус

- **Фаза 1** (канонізація ідеї) — ✅
- **Фаза 2** (скелет + контракт подій + повний фронт) — ✅ бейслайн:
  жива діорама (вода/вітер/погода), клік по POI → занурення, **живі локації з реальною
  зайнятістю** (хто де зараз), **Дошка-вісник** (пришпили тему), **гурт-розмова** (село
  сходиться на Площу, обговорює), аналітика когніції по кліку на селянина — усе кероване
  контрактом проти фікстур. Оптимізовано під слабкі пристрої (tier-resolution, кулінг
  рослин, пауза сцени за кімнатою, WebP-фони) без втрати якості.
- **Фаза 3** (ресерч агентних систем) → **Фаза 4** (прод-бек на Lapa). Деталі — `docs/adr/`.
