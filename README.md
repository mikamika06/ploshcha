# ПЛОЩА

**Українське село як дієгетична шкірка над справжньою телеметрією агентного ядра.**

Кидаєш новину на Дошку-вісник — село її обговорює. Кожна репліка, кожен крок людини по стежці — це
реальний крок ядра, показаний як побут, а не як лог. Немає HUD-панелей і кнопок «запустити агента»:
уся взаємодія через предмети в селі.

Ядро — пара суверенних українських моделей: **Mamay** розписує порядок розмови (одним викликом),
**Lapa** промовляє репліки. Виконавець не вибирає нічого — у схемі його відповіді немає поля вибору.
Спонтанність дає кубик у коді за сідом, а не імпровізація моделі.

---

## Запуск

Потрібні: `pnpm install`, `uv sync`, і `.env` з доступом до шлюзу (див. `.env.example`).

```bash
./ploshcha start        # → http://127.0.0.1:8765
```

Один процес роздає і API, і зібраний фронт. **Vite для проду не потрібен.**

```bash
./ploshcha status                 # стан, витрати, черга
./ploshcha topic 'Кажуть, за річкою бачили вовка.'
./ploshcha requeue                # оживити мертві айтеми черги
./ploshcha logs
./ploshcha stop
./ploshcha build                  # перезібрати фронт після змін у apps/web
```

Змінні: `PLOSHCHA_PORT` · `PLOSHCHA_CONDITION` · `PLOSHCHA_DB` · `PLOSHCHA_MAX_TOKENS` ·
`PLOSHCHA_MAX_USD` · `PLOSHCHA_MAX_ITEMS`.

### Як дивитись

Відкрий `http://127.0.0.1:8765`, дай сторінці ~5 секунд дозавантажитись (важкі ассети), тоді:
клікни **Дошку-вісник** → напиши тему → «Пришпилити» → **клікни цидулку**. Тема піде в чергу ядра,
селяни зійдуться на Площу, і репліки почнуть надходити по одній.

★ Тему, кинуту раніше, ніж сторінка підписалась на потік, буде втрачено: перше підключення бере лише
нові події.

### Розробка фронта

```bash
cd apps/web && VITE_LIVE_URL=http://127.0.0.1:8765 npx vite --port 5173
```

`VITE_LIVE_URL` має три стани: порожньо — грає записану фікстуру (нуль токенів); `same-origin` —
ядро роздає цю ж збірку (прод); URL — чуже ядро на іншому порті.

---

## ⚠ Безпека

- Ядро слухає **лише `127.0.0.1`** і прапорця для іншого інтерфейсу навмисно немає.
- **Автентифікації немає.**
- `POST /command` **витрачає гроші**: кладе роботу в чергу, і цикл смикає моделі сам.

Не виставляй порт у мережу й не пробрасуй тунелем. Стелі (`--max-tokens`, `--max-usd`,
`--max-items`) і kill-file (`STOP` у корені) — не косметика, а єдиний захист від забутого процесу.

## Структура

```
contracts/       ★ заморожений контракт подій — джерело правди фронт↔бек (20 типів)
packages/
  contract-ts/     TS-типи + zod-гарди зі схеми (`.strict()`: чужа форма молча відкидається)
  fixtures/        записані прогони (*.jsonl) — ганяють фронт без беку
apps/web/        Vite + TS + PixiJS: сцена, дебатна розмова, Дошка, кімнати, літопис
services/sim/
  ploshcha_sim/    ядро: domain / ports / adapters / agents / live
  evalkit/         дослідницький харнес: умови, промпти, предикати, вартість
  tests/           940+ тестів, нуль викликів моделі
data/            персони, таксономія, фікстури
eval/            golden-set + проби
infra/           docker-compose (без моделей і БД)
```

`docs/` не входить у репозиторій (gitignored) — там локальні дизайн-доки, спринти й дослідження.

## Два режими ядра

| | **віче** (прод) | дослідницькі умови |
|---|---|---|
| вхід | новина / чутка / будь-який текст | задача з відповіддю |
| успіх | розмова відбулась | збіг з gold, `pass^k` |
| `abstain` | **немає** такого стану | потрібен — чесна відмова |
| верифікатор | репліка сумніву від попа | вирок прогону |

ПЛОЩА використовує **лише** `viche`. Дослідницькі умови — вимірювальний прилад; їхніх відбитків
(`spec.sha256`) не зрушуємо, інакше старі числа стають непорівнянними.

## Тести

```bash
.venv/bin/python -m pytest services/sim          # ядро (без викликів моделі)
cd apps/web && npx tsc --noEmit                  # типи фронта
pnpm --filter @ploshcha/contract-ts test         # самотест TS-дзеркала контракту
```
