**Українське село як дієгетична шкірка над справжньою телеметрією агентного ядра.**

🔗 **Живе село: [ploshcha.org](https://ploshcha.org)**

Кидаєш новину на Дошку-вісник — село її обговорює. Кожна репліка, кожен крок людини по стежці — це
реальний крок ядра, показаний як побут, а не як лог. Немає HUD-панелей і кнопок «запустити агента»:
уся взаємодія через предмети в селі.

Ядро — пара суверенних українських моделей: **Mamay** розписує порядок розмови (одним викликом),
**Lapa** промовляє репліки. Виконавець не вибирає нічого — у схемі його відповіді немає поля вибору.
Спонтанність дає кубик у коді за сідом, а не імпровізація моделі.

---

## Запуск

Потрібні: `pnpm install`, `uv sync`, і `.env` з доступом до шлюзу (див. `.env.example`).

```bash
pnpm install
uv sync
cp .env.example .env            # і вписати LAPA_API_KEY
git config core.hooksPath .githooks   # гачки: скан секретів + заборона AI-атрибуції в комітах
```

Далі — один запуск:

```bash
./ploshcha start        # → http://127.0.0.1:8765
```

Один процес роздає і API, і зібраний фронт. **Vite для проду не потрібен.**

```bash
./ploshcha status                 # стан, витрати, черга
./ploshcha topic 'Кажуть, за річкою бачили вовка.'
./ploshcha requeue                # оживити мертві айтеми черги
./ploshcha logs
./ploshcha stop
./ploshcha build                  # перезібрати фронт після змін у apps/web
```

### Змінні середовища

| змінна | дефолт | що робить |
|---|---|---|
| `PLOSHCHA_PORT` | `8765` | порт; слухається **лише** на `127.0.0.1` |
| `PLOSHCHA_CONDITION` | `viche` | профіль пари моделей із `evalkit.conditions` |
| `PLOSHCHA_DB` | `data/ploshcha/ploshcha.db` | SQLite із чергою, витратами і **спільним** селом (теми без сесії) |
| `PLOSHCHA_MAX_TOKENS` | `300000` | стеля токенів на весь прогін; вичерпалась — цикл стає |
| `PLOSHCHA_MAX_USD` | `0.50` | стеля витрат на прогін |
| `PLOSHCHA_MAX_ITEMS` | `60` | стеля оброблених айтемів черги |
| `PLOSHCHA_VILLAGE_SEED` | `11` | сід села: те саме число — ті самі сусіди |
| `PLOSHCHA_SESSION_TTL_DAYS` | `7` | скільки тримати село гостя без жодного дотику (перегляд потоку теж дотик) |
| `PLOSHCHA_MAX_SESSIONS` | `200` | стеля кількості сіл; понад неї вилітають найдавніші |

Ключ до шлюзу (`LAPA_API_KEY` та інше) береться з `.env` — див. `.env.example`.

### Як дивитись

Відкрий `http://127.0.0.1:8765`, дай сторінці ~5 секунд дозавантажитись (важкі ассети), тоді:
клікни **Дошку-вісник** → напиши тему → «Пришпилити» → **клікни цидулку**. Тема піде в чергу ядра,
селяни зійдуться на Площу, і репліки почнуть надходити по одній.

★ Тему, кинуту раніше, ніж сторінка підписалась на потік, буде втрачено: перше підключення бере лише
нові події.

### Розробка фронта

```bash
cd apps/web && VITE_LIVE_URL=http://127.0.0.1:8765 npx vite --port 5173
```

`VITE_LIVE_URL` має три стани: порожньо — грає записану фікстуру (нуль токенів); `same-origin` —
ядро роздає цю ж збірку (прод); URL — чуже ядро на іншому порті.

## ⚠ Безпека

- Ядро слухає **лише `127.0.0.1`** і прапорця для іншого інтерфейсу навмисно немає: назовні воно
  дивиться через тунель, і випадково відкрити порт нема чим.
- **Власної автентифікації в ядрі немає** — замок ставить те, що стоїть перед ним (Cloudflare
  Access на шлях `/command`). Дивитись село може будь-хто: сцена, потік подій і стан — читання.
- `POST /command` **витрачає гроші**: кладе роботу в чергу, і цикл смикає моделі сам. Тому в ядрі
  стоїть ДРУГА, незалежна стеля — **6 команд на адресу за хвилину**. Вона лишається на місці,
  навіть якщо політику доступу налаштують криво або пароль передадуть далі.
- Стелі витрат (`PLOSHCHA_MAX_TOKENS`, `PLOSHCHA_MAX_USD`, `PLOSHCHA_MAX_ITEMS`) і kill-file
  (`STOP` у корені) — не косметика, а захист від забутого процесу: один прогін коштує ~18k токенів.
- `/layout_editor.html` — редактор розкладки для розробки, без жодного захисту; з прод-образу
  видаляється (`infra/Dockerfile`).

## Екосистема Lapathoniia

Проєкт подано до публічної вітрини Lapathoniia. Дані заявки — у `lapathoniia.project.json`
(структура з офіційного шаблону `Lapathoniia/ecosystem-project-template`), картка вітрини —
`assets/logo.png` і `assets/cover.png`.

Площа працює на двох українських моделях через Lapathoniia API: **Mamay** розписує порядок віча
хвилями по пʼять тактів, **Lapa** промовляє репліки. Виконавець нічого не вибирає — у схемі його
відповіді немає поля вибору, і саме тому пара тримається.

## Розгортання

Одна машина з Docker (ноут теж годиться) + тунель Cloudflare: роутер чіпати не треба, TLS і
публічне імʼя дає Cloudflare, домашня адреса може мінятись. Покроково — `infra/README.md`.

```bash
cp infra/.env.example infra/.env      # ключ моделі + токен тунелю
docker compose -f infra/docker-compose.yml up -d --build
```

Село кожного гостя — своє: браузер тримає в `localStorage` лише ідентифікатор, ядро — окремий
SQLite на нього. Памʼять переживає перезавантаження сторінки; село, якого не торкались
`PLOSHCHA_SESSION_TTL_DAYS` діб, прибирається саме.

## Структура

```
contracts/       ★ заморожений контракт подій — джерело правди фронт↔бек (20 типів)
packages/
  contract-ts/     TS-типи + zod-гарди зі схеми (`.strict()`: чужа форма молча відкидається)
  fixtures/        записані прогони (*.jsonl) — ганяють фронт без беку
apps/web/        Vite + TS + PixiJS: сцена, розмова гуртом, Дошка-вісник, кімнати, інспектор людини
services/sim/
  ploshcha_sim/    ядро: domain / ports / adapters / agents / live
  evalkit/         дослідницький харнес: умови, промпти, предикати, вартість
  tests/           1075 тестів, нуль викликів моделі й нуль мережі
data/            стан прода (data/ploshcha/*.db + sessions/<sid>.db на гостя — gitignored) і локальні фікстури
eval/            golden-set + проби
infra/           docker-compose (без моделей і БД)
```

`docs/` не входить у репозиторій (gitignored) — там локальні дизайн-доки, спринти й дослідження.

## Два режими ядра

| | **віче** (прод) | дослідницькі умови |
|---|---|---|
| вхід | новина / чутка / будь-який текст | задача з відповіддю |
| успіх | розмова відбулась | збіг з gold, `pass^k` |
| `abstain` | **немає** такого стану | потрібен — чесна відмова |
| верифікатор | репліка сумніву від попа | вирок прогону |

Площа використовує **лише** `viche`. Дослідницькі умови — вимірювальний прилад; їхніх відбитків
(`spec.sha256`) не зрушуємо, інакше старі числа стають непорівнянними.
