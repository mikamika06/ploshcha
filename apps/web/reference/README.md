# reference/ — рендер-референс (НЕ застосунок)

`scene_pixi.html` + `pixi.min.js` перенесені зі старої лабораторії
(`~/lapa-arena/design/`) як **референс для порту** у Фазі 2c.

Це самодостатній декоративний прототип сцени (PixiJS v7.4.2): запечена земля, вода-шейдер
із flow-map, процедурна рослинність із масок, BFS-ходьба агентів, вітер через skew,
глибина через zIndex, дубова рамка, інтро-хмари. Агенти в ньому **випадкові** — жодного
звʼязку з беком.

**Не обслуговується Vite і не є частиною збірки.** Логіку звідси розкладаємо в типізовані
модулі `apps/web/src/{scene,agents,...}` і підключаємо до контракту подій. Після порту цей
файл лишається лише як довідка.
